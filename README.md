# 项目介绍

## 工业物料匹配系统

针对物料描述不统一、规格约束多、标准名称存在差异的问题，从文本中提取规格与属性条件，检索候选物料并进行重排序。结合标准等效关系筛选匹配项，辅助核对物料选型结果。对未找到匹配项和处理过程异常分别给出状态，便于人工复核与问题排查。

## P&ID 图纸智能检索

将工艺管道及仪表流程图中的设备、仪表位号识别为可搜索的信息，帮助使用者从图纸中查找目标对象。输入位号后，可查看对应的 PDF 页面，并通过位置跳转与高亮找到图中目标，串联位号识别、检索与原图核对流程。

## 文档知识库与 RAG 问答

面向文档资料的查询与问答，将知识检索与大模型回答结合，支持流式输出，并在回答中提供来源引用和页码，方便回到原文核对依据。系统对接独立的文档入库模块，将知识服务、业务接口和配置分层组织，支持检索与问答能力的集成。

## 热点资讯聚合与推送 · TrendRadar

聚合多个平台的热点资讯，按关键词筛选关注内容，并支持通过多种渠道发送通知，便于集中追踪感兴趣的话题。基于开源项目 [sansan0/TrendRadar](https://github.com/sansan0/TrendRadar)。
